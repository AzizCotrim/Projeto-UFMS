# Projeto-UFMS

Sistema de apoio ao processo educacional, desenvolvido como parte do projeto de extensão da UFMS “Educação para Todos – App de Estudo Ativo”.

## Descrição

Este protótipo de aplicação web oferece uma interface simples e intuitiva para:
- Visualizar e gerenciar agenda escolar (calendário de eventos e prazos);
- Cadastrar e acompanhar trabalhos e tarefas;
- Consultar notas de diferentes disciplinas;
- Exibir comunicados e avisos em estilo “post-it”;
- Registrar resumos de aulas (relatórios);
- Enviar mensagens e conteúdos específicos para turmas, professores ou responsáveis.

O objetivo é facilitar a comunicação entre professores, alunos e responsáveis, centralizando informações em um único painel.

## Funcionalidades

- **Barra lateral de navegação** com os módulos: Agenda, Trabalhos, Notas, Avisos, Relatórios e Enviar.  
- **Agenda**: calendário interativo gerado dinamicamente via JavaScript.  
- **Trabalhos**: painel de cards com status (Pendente / Entregue) e data de entrega.  
- **Notas**: listagem de notas por disciplina.  
- **Avisos**: quadro de “post-its” para comunicados diversos.  
- **Relatórios**: área para escrita de resumos de aulas com data e matéria.  
- **Enviar**: formulário para direcionar conteúdos a turmas e perfis de usuário.

## Tecnologias

- **HTML5** e **CSS3** para marcação e estilização.  
- **JavaScript** + **jQuery** para lógica de interações e geração de conteúdo dinâmico.
